Tag formats, by file type

What's read

Across both tag formats, Raza Songs reads the same set of fields into a unified view:

  • Title
  • Artist
  • Album
  • Genre
  • Track and disc number
  • Year
  • Embedded artwork

Audiobooks (M4B)

M4B files carry the same tag fields as M4A, plus chapter markers built into the container. Raza Songs reads those alongside the standard tags, so an audiobook shows up as itself — not just a very long song.
